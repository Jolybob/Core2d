# Core2D

Small browser-first 2D survival prototype built with Phaser 4 + TypeScript + Vite.

## Prototype

- Procedurally generated tile world
- WASD / arrow movement
- Camera follow + pixel-art rendering
- Left-click mining
- Resource counter
- Deterministic world seed

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Direction

The prototype is intentionally small. The next systems should be chunk streaming, proper tile data, inventory/crafting, enemies/combat, persistence, then multiplayer with an authoritative server.
